===================================================================
STAGECHART — DOBGÉP (GROOVE ENGINE) HANGMINTÁK MAPPA (audio/drums/)
===================================================================

A StageChart Groove Engine beépített, dinamikusan modellezett akusztikus
dobmotorral rendelkezik (Pop/Rock 8-beat, Ballad 16-beat, Country/Folk,
Akusztikus 6/8, Latin/Bossa, Swing).

Ha saját akusztikus dob sample-öket szeretnél betölteni:
- kick.wav / kick.mp3          (Lábdob)
- snare.wav / snare.mp3        (Pergő)
- sidestick.wav / sidestick.mp3 (Káva / Rimshot)
- hihat_closed.wav             (Zárt lábcin)
- hihat_open.wav               (Nyitott lábcin)
- shaker.wav                   (Shaker / Csörgő)

Ezeket a Beállítások -> Audio & Csatorna-routing menüben egyetlen kattintással
betöltheted a memóriába.
